Integra l'app "La Provvidenza ODV" nel sito WordPress www.laprovvidenza.it.

== Descrizione ==
Questo plugin permette di accedere e gestire le prenotazioni (ambulanze e trasporto
disabili) direttamente dal PC, tramite il sito WordPress dell'associazione.

Funzioni:
* Pagina impostazioni (Impostazioni -> Provvidenza App) per inserire l'URL dell'app.
* Shortcode [provvidenza_app] da inserire in qualsiasi pagina.
* Pulsante di accesso rapido + app incorporata (iframe).

== Installazione ==
1. Dashboard WordPress -> Plugin -> Aggiungi nuovo -> Carica plugin.
2. Seleziona il file provvidenza-odv-app.zip e attiva il plugin.
3. Vai in Impostazioni -> Provvidenza App e incolla l'URL dell'app (ottenuto dopo la pubblicazione con il pulsante Publish).
4. Crea una pagina (es. "Area Riservata") e inserisci lo shortcode [provvidenza_app].
5. Apri la pagina dal PC ed effettua il login.

== Note ==
Se l'app incorporata non si visualizza (alcuni provider bloccano gli iframe con intestazioni
di sicurezza), imposta la modalita' su "Solo pulsante": l'app si aprira' in una nuova scheda.
